# Andrea Taccani — academic website

Source for [andreataccani.github.io](https://andreataccani.github.io), a dependency-free
static website hosted with GitHub Pages.

## Structure

- `index.html`: home page
- `research/`: research interests and current thesis
- `cv/`: web CV
- `teaching/`: teaching record
- `contact/`: contact details
- `assets/css/site.css`: shared visual system and responsive styles

All pages use semantic HTML, visible keyboard focus, reduced-motion support,
page-specific metadata, and a print stylesheet for the CV.
